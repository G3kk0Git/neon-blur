# NEON BLUR 3D

Browser-Rennspiel (eine HTML-Datei, three.js). Zum Hosten einfach den Ordner veröffentlichen (z. B. Netlify).

## Chordwave (Ordner `chordwave/`)

Akkord-Synth im Browser: Grundton + Akkordtyp wählen, die Stimmen gleiten zum nächsten Akkord. Mit Loop, Hall, Echo, Filter, LFO, Presets sowie WAV- und MIDI-Export. Nach dem Hosten unter `/chordwave/` erreichbar und als App installierbar.
